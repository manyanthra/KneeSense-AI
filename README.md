#KneeSense-AI

An intelligent medical imaging platform for automated Knee Osteoarthritis (OA) assessment and patient-specific implant planning. The project uses a trained ML model to classify Kellgren–Lawrence (KL) grades from knee X-rays and generates a clinician-friendly report through a modern Flask web application.

Key Features:
AI-based KL Grade (0–4) prediction
Confidence score visualization
Patient demographic management
Knee X-ray upload and analysis
Clinical report generation
Modular architecture for future meniscus segmentation and implant sizing

Tech Stack: Python · Flask · Scikit-learn · OpenCV · Joblib · HTML/CSS
